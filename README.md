# Ellty-Assignment

## Prerequisites
- [Node.js](https://nodejs.org/) (Latest LTS recommended)

## Installation & Usage

### Install Dependencies
```sh
npm install
```

### Run Server in Development Mode
```sh
npm run dev
```

### Run Server in Production Mode
First, build the server:
```sh
npm run build
```
Then, start the server:
```sh
npm run preview
```
